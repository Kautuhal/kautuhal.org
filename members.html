🏅 Rank & Class

⚔️ Rank (F → S)
What you can currently do. It measures capability, never worth. Rank can earn influence, never privilege.
🗺️ Class
Where you're exploring now: AI, Game, Blockchain, Web, App… Your Class is your niche in computer science, shaped by your curiosity as you explore new territory.

Each rank is a chapter, not a score:

  • F · Fable
  • E · Elegy
  • D · Drama
  • C · Canto
  • B · Ballad
  • A · Allegory
  • S · Saga

Pegged to college level: F is a total newbie (milestone: the first Git commit), C is command of one language and a framework, S runs a startup of their own.

🚧 Exact skills for each rank are still being decided with the members, so real ranks aren't assigned yet.
